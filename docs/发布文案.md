# 发布文案（采蘑菇 / Nexus / 贴吧 通用）

## 标题

【功能 MOD】GuardRed — 霸体 · 相杀期间伤害转红血（只影响自己）

## 一句话简介

霸体 / 相杀（铁壁）状态下挨打不再永久掉血，伤害全部变成可回复红血，按游戏原本节奏慢慢补满。

## 正文

《怪物猎人：荒野》里被打一下，掉的血只有一半能回（红血上限 = 新 HP + 0.5×伤害），
另一半是永久损失。这个 MOD 只做一件事：**在你处于铁壁/相杀窗口时，把那一半也还给你**。

- 普通挨打：和原版完全一样，掉 21 只回 10.5
- 相杀命中、肩撞、全解等铁壁窗口内挨打：掉 21，**21 点全部可回**，随后 HP 每 1.5 秒 +1 慢慢补满

不是无敌：HP 照样掉，只是掉下去的部分能回来；一击把血打到 0 仍然会猫车。
不修改任何游戏文件，只改本机运行时数值。

## 效果对比

| 场景 | 原版 | 装了之后 |
|---|---|---|
| 普通挨打 | 永久损失约一半 | 不变 |
| 铁壁/相杀窗口挨打 | 永久损失约一半 | 全部可回 |
| 蓄力起手（只有 SUPER_ARMOR） | 永久损失约一半 | 不变（默认只认铁壁） |

## 前置

- REFramework（nightly 版）
- 游戏：Steam build 24705561（2026-10 实测）

## 安装

1. 先装 REFramework：把 `dinput8.dll` 放到游戏根目录
2. 把本包的 `reframework` 文件夹解压到游戏根目录，覆盖合并
   → `<游戏目录>\reframework\autorun\guard_red.lua`
3. 启动游戏，`Insert` 打开菜单 → `Script Generated UI` → `GuardRed`

## 面板

- 启用：总开关
- 仅铁壁/相杀时生效：默认开
- 红血方案(关闭=补绿血)：默认开；关掉会变成“受伤直接补血”（更强，备用）
- 调试日志：默认关

## 已知限制

- 一击致死不防（红血只影响可回上限）
- 反应等级照常：强攻击照样能打飞你，只是伤害转成了红血
- 游戏或 REF 更新后可能失效
