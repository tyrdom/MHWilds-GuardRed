# 游戏内操作清单（发现阶段）

目标：用一次游戏内会话，把「血量 / 红血 / 霸体」的真实字段和数值变化录下来。
脚本只读不写，不会改你的存档数值；但仍旧建议先备份存档（见文末）。

## 0. 部署（在电脑上，我这边已做）

`powershell -File tools\deploy.ps1 -WithScan` 会把两个脚本放进游戏目录的
`reframework/autorun/`：

- `guard_red.lua`（正式脚本，当前是空转）
- `zz_guardred_scan.lua`（发现脚本，会往日志里写 dump 和数值变化）

## 1. 启动游戏

- 从 Steam 正常启动 `Monster Hunter Wilds`。
- 进标题界面后按 `Insert`：
  - 能弹出 REFramework 菜单 = 注入成功。
  - 菜单里应当能看到 `GuardRed Scan` 这一栏（在 `ScriptRunner` 里也能看到
    `zz_guardred_scan` 已加载）。
- **如果游戏启动即崩溃 / 按 Insert 没反应**：说明 REF 版本和当前游戏 build 不匹配，
  先把游戏根目录的 `dinput8.dll` 改名（例如 `dinput8.dll.bak`）再启动确认能进游戏，
  然后告诉我，我换新版 REF。

## 2. 进入可战斗的场景

随便进一个任务（下位任务、小怪多的图最好），**保证会被打到但不会死**。

## 3. 按顺序做这几件事（每步之间停 2~3 秒）

日志按时间顺序记录，有间隔我才能分清哪段是哪段。

1. **静止 5 秒**（什么也不做，让我拿到基线数值）。
2. **普通受击 1 次**：让一只小怪打你一下（不要格挡、不要翻滚）。
3. **霸体动作**：用一个你确定有霸体的动作（大剑蓄力、双刀乱舞、斩斧零解之类），
   连续做 **3 次**，每次间隔 2 秒；最好是在小怪旁边做，让动作期间也挨一下打。
4. **相杀 1 次**：找一只怪，用相杀（对撞）成功一次。
5. **再普通受击 1 次**。

> 如果某一步做不出来（比如当前武器没有相杀），跳过并在最后告诉我跳过了哪步。

## 4. 结束

- 按 `Insert` 打开菜单，看一眼 `GuardRed Scan` 面板里有没有一堆
  `xxx._HitPoint = 123.0` 这样的行：有 = 抓到了，截个图也行。
- 正常退出游戏（回到标题再退出即可）。
- 回来告诉我：完成了哪几步、跳过了哪步、面板里看到了什么字段名。

我会读游戏目录的 `re2_framework_log.txt`，把字段名 / 霸体标志填进
`guard_red.lua` 的 `CONFIG`，再做实测。

## 备份存档（可选但推荐）

存档在 `C:\Program Files (x86)\Steam\userdata\<你的ID>\2246340\remote\`，
整个 `remote` 文件夹复制一份即可。
